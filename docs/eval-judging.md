The original key (`data/eval/questions.jsonl`) was not changed. "v2" is a second, graded key
(`data/eval/judgments/qrels-v2.jsonl`) built from the grades of an AI judge: vertex-ai-claude-opus-4.8, served by a LiteLLM gateway (the Anthropic key's monthly limit was reached, and Opus 5.5 is not on the proxy). It is a different model from the Sonnet 5.5 agent that wrote the original key, but both are Claude models, so a shared family bias is possible. A run with a GPT-5.x model through the same proxy would be the next independence check; it was not run. v2 gold = paragraphs graded 2.
Treat v2 as a better estimate, not as ground truth: see "Review list" for what a human should check.

How to read the movement: v2 is a much wider key (median 10 grade-2 paragraphs per question against 2 originally; 536 added gold paragraphs), so part of the rise in recall and most of the rise in MRR is simply that there are more right answers to hit. One thing argues it is not only a generous judge: recall still rises although its denominator grew several-fold, so the extra paragraphs are being retrieved. Two things argue for caution: the judge is a Claude model like the key's author, and it graded about one paragraph in nine as a direct answer. Whatever the exact size of the effect, the original key was too narrow to be used as the only measure.

Metric definitions (code: `py/rag/eval/judging/metrics.py`):

- recall@k and MRR: as in `rag.eval.metrics` (a hit covers all the paragraphs of its chunk), only the gold set differs: original = the key's `expected_paragraph_ids`; v2 = paragraphs graded 2.
- nDCG@10: graded gain `2^grade - 1` (grade 0 = 0, grade 1 = 1, grade 2 = 3). Ranking = de-duplicated paragraph ids of the hits in rank order, cut at 10 paragraphs. DCG = sum of gain / log2(rank + 1); nDCG = DCG / DCG of the ideal order of the graded paragraphs. For the original key every gold paragraph has grade 1 (gain 1), so the two columns are on the same scale. A paragraph nobody graded counts as 0.
