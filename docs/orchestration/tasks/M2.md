# M2: comparison eval, "Claude + MCP tools" vs `/ask` (Gate 1)

**Read first (targeted):** `docs/orchestration/tasks/mcp-common.md` (binding), **`docs/interfaces-mcp.md` §2, §3 and §7 (binding: your seams)**, `packages/contract/src/mcp/*.ts` + `fixtures/Mcp*.json`, `data/eval/owner-review.jsonl`, the item format of `data/eval/questions.jsonl` (first 3 lines only), `py/rag/eval/judge.py` (`judge_support`, `make_llm`, `price_usd`), `py/rag/eval/metrics.py`, `py/rag/answer/llm.py` (how the app builds its Anthropic client and logs cost), `docs/learn/S6.md` §1 and §3 (the existing eval).

## Target
A harness in `py/rag/eval/agentic/` that answers questions with **Claude Sonnet 5.5 (`claude-sonnet-5-5`) over the Anthropic API using our MCP tools**, and the same questions with the existing `/ask` pipeline, then writes a side-by-side comparison to `docs/mcp-comparison.md`.

## Change
1. **MCP client side:** start the server over **stdio** with the SDK's client (`mcp` 2.3.x; newer than your training data: read the installed package and the official docs first), `list_tools`, convert each tool to an Anthropic tool definition (name, description, `input_schema` = the tool's `inputSchema`), system prompt = the server's `instructions`. **One server process per run**, reused across questions (model loading takes 10–30 s).
2. **Tool loop:** Messages API with tools; execute each `tool_use` through the MCP session; feed results back as `tool_result` (the JSON text); stop at the final answer or **8 tool calls per question** (then ask for a final answer without tools). Use **prompt caching** (cache_control on the tools and system prompt) to cut input cost. Client built exactly as §7 says (`rag.config`, never SDK env defaults); log every call with `rag.index.log_cost(…, purpose="agentic")`.
3. **Development without spending:** a fake MCP server (`fake_server.py`, the six tools with the contract schemas and instructions, returning the contract fixtures) and a scripted fake Anthropic client (returns `tool_use` blocks, then a final text). CI tests run the whole loop with both fakes over stdio, offline.
4. **Runs** (after M1 merges, against `python -m echr_mcp --transport stdio` on your DB `echr_m2`):
   - the 10 owner-review questions **×3** (or-10 is a second turn after or-01 in the same conversation; for `/ask`, which is stateless, ask it alone);
   - a fixed random **30** retrieval questions **×1** (§7: seed `20261104`, items with expected paragraphs; commit the ids in `data/eval/agentic/subset.json`);
   - the same questions through `/ask` in-process (`rag.answer.answer(conn, {"question": q})`; ×3 for the owner-review set, ×1 for the subset).
5. **Metrics per question and system** (store raw results as JSONL in `data/eval/agentic/`):
   - answer text and tool calls (name, args, result bytes, latency);
   - **agentic recall** = gold paragraphs among every paragraph id returned to the model in any tool result (search hits, get_paragraphs, get_case operative provisions); for `/ask`, among the paragraphs in its generation context (§7);
   - **citation accuracy** with the existing judge (`judge_support`, unchanged): split the host answer into claims (sentences/bullets) with the `paragraph_id`s / `cite`s each contains; headline = claims judged supported by **all their citations together**; also the per-citation figure; same for `/ask`;
   - **verbatim-quote rate**: every quoted passage in the answer attributed to a cited paragraph, checked with the server's `check_quote` (free, deterministic);
   - **owner-review shape check**: the `checks` in `owner-review.jsonl` (deterministic ones in code; `judge` ones in one judge call per answer); pass = all checks pass; report the pass rate over 3 samples;
   - tokens (input, output, cache read/write), cost, latency.
6. **`docs/mcp-comparison.md`:** setup (models, server, dates, sample sizes, seed); a side-by-side table (rows: shape pass rate, citation accuracy together / per citation, agentic recall, verbatim-quote rate, tool calls per question, tokens, cost and latency per question; columns: Claude + tools, `/ask`; split by owner-review set and retrieval subset); a per-question owner-review table; the **10 owner-review transcripts** (sample 1 of each: question, each tool call with arguments and result size, the final answer); a short "what we saw" section (facts only, no recommendation; the decision memo comes later). Leave a `## Decision memo` heading with "to be written after the owner review".
7. `docs/learn/M2.md` (5 sections; try-its include a one-question dry run with the fakes, reading a transcript, and re-running one question live with its cost shown).
8. CLI: `cd py && uv run --group ml python -m rag.eval.agentic --set owner-review|subset|all --systems mcp,ask --repeats N --max-cost <usd> [--fake] [--only or-03,or-07]`, and root script `eval:agentic`.
