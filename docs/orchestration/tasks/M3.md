## Change
1. **Image** `infra/deploy/Dockerfile` (+ `infra/deploy/Dockerfile.dockerignore`): one image for the FastAPI app and the MCP server (`python -m echr_mcp --transport http --port 8100`, M1's entry point per `docs/interfaces-mcp.md` §1; until M1 merges, build and test the API path and leave the MCP service ready to switch on). 2. **Compose** `infra/deploy/compose.yml` (project name `echr-deploy`): ParadeDB (same image as `infra/docker-compose.yml`) on host port **5434**, the API on **8003**, the MCP server on **8103**. A script `infra/deploy/load-snapshot.sh` that loads the snapshot corpus into the compose DB (e.g. `pg_dump` of your `echr_m3` restored into it; or `rag.ingest --source snapshot` inside the container; measure whichever you use). 3. **Measure** (numbers, not estimates): image size; RAM at idle and during a search/rerank (`docker stats`); cold start = container start → first successful `/health`, first `/search` and first MCP `tools/list` + `search_case_law` call; warm search latency.
4. **`docs/hosting-options.md`:**
   - **Requirements** derived from the measurements (RAM, CPU, disk, always-on vs scale-to-zero, Postgres with pgvector + BM25).
   - **Netlify first:** what Netlify can and can't host here (Functions/Edge limits: memory, timeouts, bundle size, long-lived streamable HTTP; Netlify DB / its Postgres provider and whether pgvector and a BM25 extension such as `pg_search` are available), and the realistic hybrid (e.g. the web app on Netlify, the API + MCP container elsewhere).
   - **Compare 3 hosts** that can run the container next to Postgres with pgvector + BM25 (at least one Netlify-based or Netlify-adjacent option): monthly cost at our size (show the arithmetic and the pricing page date), RAM/CPU, whether ParadeDB (`pg_search`) runs there or which **BM25 fallback** works (e.g. Postgres full-text `ts_rank`, an in-process BM25 index) and what that would cost us in retrieval quality, cold starts, TLS/custom domain, data residency.
   - **Auth for remote MCP:** what **claude.ai custom connectors** and **ChatGPT** (connectors / apps / developer mode, whichever is current) require from a remote MCP server: transport, public HTTPS URL, OAuth 2.1 / dynamic client registration / authless options, allow-listing, plan requirements. From their **current official docs, linked and dated**; don't guess.
   - **Recommendation:** one option, its monthly cost, the steps to deploy it (not executed), and the risks.
5. `docs/learn/M3.md` (5 sections; try-its: build the image, start compose, load the snapshot, call `/health` and an MCP tool, read `docker stats`).
