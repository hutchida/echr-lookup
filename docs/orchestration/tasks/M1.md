## Target
A new package `py/echr_mcp/` that exposes the retrieval layer as six read-only MCP tools (`search_case_law`, `get_paragraphs`, `get_case`, `count_cases`, `corpus_info`, `check_quote`) over **stdio** and **streamable HTTP**, using the official Python MCP SDK (`mcp` 2.3.x, already a dependency). Claude (Desktop, Code, or M2's harness) does the reading and writing; the server supplies cited evidence and never calls an LLM.

Models load and warm once at startup.
